# 백엔드 docs — 문서 지도

> v0.1 · 2026-10-29 · 초안(팀 확인 중) · 정리 진희

다자바 백엔드(`dajaba-backend`)의 규칙과 설계를 **한곳에 모아 둔 요약본**이에요. 노션에 흩어진 설계 문서·규약·회의 결정과 리포 코드를 읽고 정리했어요. 코드를 짜거나 PR을 리뷰할 때 노션을 처음부터 뒤지지 않아도 되게 하려는 문서예요.

- **정본은 여전히 노션과 리포 코드예요.** 이 문서와 다르면 노션(설계·규약·회의 결정)과 리포 코드가 맞아요. 다른 곳을 발견하면 아래 "누가 고치나"의 담당자에게 알려 주세요.
- 문서끼리 같은 내용을 다르게 적은 곳은 **더 최근 문서를 따랐어요.** 어디를 어떻게 골랐는지는 `08_decisions.md` "문서끼리 다른 곳"에 다 적어 뒀어요.
- 규칙 한 줄마다 `[출처]`를 달았어요. 출처 약어는 아래 표에 있어요.
- 마지막 동기화: **2026-10-29 (목)** · 정리: 진희

## 읽는 법 — 확정 vs 초안

담당자별 설계 문서(준혁·지윤·채영)는 아직 **초안(v0.x)**이고 계속 보완 중이에요. 그래서 이 문서에서는 두 가지를 구분해요.

| 표시 | 뜻 | 리뷰에서 |
|---|---|---|
| (표시 없음) | 가이드·레퍼런스·규약·회의에서 **확정된** 규칙 | 기준으로 써요 |
| **〔초안〕** | 담당자 문서의 **지금 안**. 담당자가 바꿀 수 있어요 | 참고만 해요. 다르게 짰으면 "초안과 다른데 의도한 건가요?" 질문으로 |
| **〔확인 필요〕** | 문서끼리 다르거나 아직 안 정해진 것 | `08_decisions.md` 미결 표에 모아 둠 |
| **〔제안〕** | 노션엔 아직 없지만 진희가 **새로 제안**하는 규칙 (10/29) | `[제안]` 코멘트로만, `[반드시]` 아님. 팀이 받아들여 노션에 들어가면 표시를 지워요 |

각 문서 맨 위 한 줄(`v0.x · 날짜 · 상태`)이 그 문서의 버전이에요. 내용이 바뀌면 버전과 날짜를 올려요. 〔제안〕

## 팀 확인 부탁 — 먼저 봐 주면 좋은 것 다섯

자세한 건 `08_decisions.md` 미결 표에 있어요. 리뷰 기준을 정할 때 걸리는 것만 골랐어요.

1. **승인·반려 API 경로** — `/approvals/{draft_id}/…`(계정·권한, STR 명세) vs `/approvals/{case_no}/…`(CASES 명세 제안). 채영·지윤
2. **목록 응답 모양** — 코드를 문서 모양 `{items, page, size, total}`으로 맞추는 중이에요([SCRUM-39](https://dajaba.atlassian.net/browse/SCRUM-39), 테스트 통과). `total_pages`는 없어지니 프론트에서 `ceil(total / size)`로 계산해 주세요. 진희
3. **`batch_runs` 재실행 규칙** — 회의(안건 14·21)는 "적재·룰 스캔만 성공 후 재실행 금지, 점수·케이스 생성은 재실행 허용"인데 `V004` 인덱스는 네 배치 전부 막아요. SD 명세는 `SCORE_RETRY` 유형을 제안했는데 회의에서 없애기로 했어요. 준혁·진희
4. **`transaction_id` 발급** — 레퍼런스·SD 명세는 "CSV 행 번호를 그대로", 안건 1·ML 규약은 "DB가 자동 발급 + `source_files`로 원본 행 추적". 최신인 후자를 따랐어요. 준혁
5. **은행 ID 앞자리 0** — 규약은 "문자열로, 앞 0 보존"인데 SD 명세는 두 원천 파일의 은행 ID 형식이 달라서 그대로 두면 조인이 전부 실패한다고 적었어요. 어느 형식으로 맞출지. 준혁

## 진희 제안 여섯 — 의견 주세요 〔제안〕

노션엔 없지만 있으면 덜 헷갈릴 규칙이에요. 각 문서 본문에 〔제안〕 표시로 넣어 뒀어요. 괜찮으면 노션에 옮기고 표시를 지울게요.

|---|---|---|
| 1 | 리뷰에서 반복되는 지적을 `ArchitectureTest` 규칙으로 (컨트롤러 → 리포지토리 금지 등 4개) | `02_structure.md` §7 |
| 2 | 에러 코드 목록은 한 장으로, 새 코드는 표에 먼저 | `03_shared.md` §2 |
| 3 | Flyway 번호 예약을 노션 표 한 장으로 | `05_flyway.md` §1·§3 |
| 4 | 감사 시각은 UTC `Z`, 원천 거래 시각은 시간대 없음 — 구분해서 | `01_code_rules.md` §5, `03_shared.md` §3 |
| 5 | `shared/`·보안 설정이 바뀌면 #개발에 네 줄 공지 | `03_shared.md` 맨 위, `01_code_rules.md` §10 |
| 6 | 문서 맨 위에 `버전 · 날짜 · 상태` 한 줄 (이 docs부터 적용) | 이 README "읽는 법" |
